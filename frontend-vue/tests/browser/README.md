# Agent v3 浏览器 Mock 回归

`agent-v3.smoke.js` 是单文件 `async (page) => { ... }` 入口，可把它的**绝对路径**直接传给 Playwright 工具 `browser_run_code_unsafe` 的 `filename` 参数。它不是 Node 命令行程序，不依赖额外测试包。

本文件整理自已验证的 `setup.js`、`actions.js`、`patches.js` 和 `extras.js`。任务数据由一份基础 Run 与状态差异构造；角色、模型、费用和素材均为演示数据，不代表实际模型质量或真实账单。

## 使用条件

1. 先准备本地前端预览页面。此脚本不构建、不启动服务，也不连接数据库。
2. 使用独立测试页面，确保该浏览器上下文没有会绕过页面请求拦截的 Service Worker。不要复用含真实业务请求的页面。
3. 当前页面为 `http://localhost:<端口>` 时，脚本使用该端口；否则使用 `http://localhost:4173`。可先打开目标本地预览页再运行脚本。
4. 将文件路径传给 `browser_run_code_unsafe.filename`，一次执行完整流程。不要拆成多个依赖 `globalThis` 的工具调用；工具的 JavaScript 虚拟机会在调用之间重置。

脚本会先导航到 `about:blank` 停止旧页面轮询，再安装拦截器并进入 Agent Studio。它使用演示登录信息，会覆盖测试页面所在源的 `auth`、`settings` 本地存储。

## 网络边界

- **全部 `/api/**` 请求只返回内存中的假 API 响应，绝不转发真实后端。** 未匹配 API 一律中断。
- 只允许同一 localhost 预览源的普通 GET/HEAD 静态资源请求；其他源或非预期请求一律中断。页面已有的 Google Fonts 请求会被中断并单独计数，不作为失败；其他被阻断请求会令回归失败。
- 图像与 ZIP 来自内联数据；不会下载外部图片、调用模型或产生费用。
- 同一请求键重放返回原回执；相同键但内容变化返回冲突。传输故障与报价故障也由拦截器模拟。
- 执行结束后保留拦截器，因为页面还可能轮询。**请关闭测试页面后再移除拦截器，不要把仍在轮询的页面接回真实后端。**

## 已整理的检查

- 计划审核、协作记录分页（30 + 7 条）、费用与修复额度边界。
- 计划精确版本、传输失败后复用请求键。
- Producer 提问与图片选项、精确关键帧节点审批。
- `attention` 且仍有待处理操作时的显式恢复。
- 补丁重新获取报价、保留后代风险确认、only/cascade 切换、迟到响应和报价失败。
- 使用当前 cascade 报价批准修改、素材包下载与结果验收。
- 轮询不清除修复额度、修改意图、节点展开状态和当前补丁报价；版本变化使旧报价失效。
- A 的批准请求延迟 450ms、B 的详情延迟 1000ms：用户转选 B 后，A 先返回的回执不能抢回选中任务。
- 列表在请求时保存旧快照并延迟 800ms：期间批准成功后，旧列表迟到不能把历史状态改回待审核。竞态等待均有不足 10 秒的硬上限，并断言实际响应先后顺序。
- 慢动作、慢下载跨轮询仍能完成；下载携带演示鉴权；服务器禁止人工批准时仍可拒绝补丁。
- 1440px / 400px 各自的亮色、暗色页面无横向溢出；同时检查 document、body 和 main 内部元素的右边界。
- 空文本与纯空白不能提交，快捷键也不会创建任务；有效文本可启用提交按钮但测试不发送创建请求。
- v1/v2 历史记录继续进入旧面板，不出现 v3 计划审批控件。

包含七类 v3 Run 数据，并补充 v1/v2 历史投影：计划审核、待提问、预览门、执行中、补丁待审、结果待验收、未知操作恢复。浏览器断言失败会抛出异常；成功返回检查清单、四种布局测量、动作与报价请求计数、页面异常及阻断请求计数。为保持脚本独立，不自动保存截图；主代理可另行截取到忽略目录。

当前内联 PNG 仅作占位，ZIP 是空包，未提供 MP4 数据。本脚本不验证视频解码、FFmpeg、真实下载内容、后端审批算法或生成效果。布局断言验证尺寸和溢出，不替代人工视觉评审。
