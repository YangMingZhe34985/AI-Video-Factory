# 静态画面提示词（写作标准 · 已由 Claude 审定 2026-10-22）

本标准提炼自经典工作流的“首帧生图”与“文生图转图生图”系统提示词。图片决定后续视频的画质、角色一致性和起点，用词要精准浓缩，避免冗长。

## 通用结构（写成一段话）

画质与风格 → 主体外观（五官或毛色、体型、服装配饰、表情）→ 静态姿态 → 场景与环境 → 光影与色调 → 构图（景别、机位、主体位置、横/竖构图）。一般 120–300 字。有 StoryPackage 时以统一的 style.prompt_prefix 开头，保证全片风格一致。

## 按用途写

- **首帧 / 关键帧**：必须写明主体在这一帧的**静态姿态**（例如“正低头凑近灯笼，前爪踏在雪中”）。它是后续视频动作的起点锚点，姿态应是本镜头动作的开始而不是结束；锚点偏差会导致视频突变或过渡生硬。镜头里有关键交互（叼着、握着、骑着等）时，首帧就画成该交互已经成立的状态，并写清接触部位（例如“灯笼提梁衔在嘴里”）。画面中要预先包含本镜头稍后会用到的关键元素（例如之后要走向的小木屋应出现在远景），避免视频里凭空出现。
- **角色定妆图（身份参考）**：单一角色，全身或四分之三身，正面或微侧，姿态自然中性，背景简洁干净，光线均匀；完整写出可识别特征（五官或毛色花纹、体型、服装与配饰的颜色材质）。后续所有镜头都会引用这张图，宁可清楚，不要花哨。
- **图生图（i2i，带参考图）**：必须明确写“严格保留参考图中角色的形象，包括面部特征、发型（或毛色花纹）、身材比例与服装配饰”；多角色时逐一写保留约束。然后只写本帧的新场景、新姿态与构图，参考图里已有的外观不要改写成另一套描述；剔除可能导致形象重新“抽卡”的不确定描述。需要保留参考身份时必须用支持参考的 i2i，t2i 无法直接绑定附件。
- **风格候选图（N 种风格各一张）**：主体、场景、构图保持一致，只有风格段不同；每种风格写出具体特征（例如水彩：半透明晕染、纸张纹理；浮世绘：平涂色块、清晰墨线、靛蓝与朱红），不能只写风格名称。

## 规则

- 一个提示词只描述一个静态瞬间，不塞故事节拍和连续动作。
- 不需要文字时写“画面无文字、无字幕、无水印”。浮世绘、海报、招牌街景等风格特别容易生成伪文字，一定要写明。
- 构图与画面比例参数一致。
- 成年人物规则同 t2v-prompt-writing。
- 引用只能用已确认工件或计划内引用，等待角色生成时留下正确依赖，不捏造占位 ID；继承尾帧或使用用户首帧时，不再生成新的首帧。
- Prompt Smith 只修订被授权的提示字段，不改模型、时长、依赖、参考、预算或审批状态。

## 示例（演示数据，必须按实际需求重写，不可照抄）

定妆图：

> 高品质三维卡通渲染质感，细节清晰，柔和均匀的棚拍光。一只成年潘布鲁克柯基，橘白相间的短毛，大而直立的耳朵，深棕色眼睛，穿着一件明黄色带帽雨衣，雨衣胸前有一颗白色圆扣。正面微侧站姿，四足自然着地，神情开朗。纯净的浅蓝灰色背景，没有多余道具，全身构图，主体居中。画面无文字、无水印。

图生图关键帧：

> 严格保留参考图中柯基的形象，包括毛色花纹、耳朵与眼睛、体型比例和明黄色雨衣。雨天的老街边，柯基站在一个映着路灯的小水坑前，身体朝向画面左侧，前爪微抬，正准备起跳。湿漉漉的石板路反射着暖黄路灯，细雨斜落，远处是模糊的店铺橱窗灯光。低角度横构图中景，柯基位于画面右侧三分之一处。画面无文字、无水印。
