07

Skill 是有契约的能力，不是一段暗号

统一输入输出类型、参数校验、产物引用、费用语义、幂等键和错误分类。旧 DAG 按能力拆用，避免每次跑满 19 个节点。

新增 多模态理解

文本 + 图片 / 视频 → 素材语义、人物特征、时间标注和不确定项。视频按场景抽帧，按需转写音频；不靠少量帧臆测整段。

新增 网页与图像研究

查询 → 带来源的证据、候选图与视觉描述。检索服务商可替换；资料作为数据，不作为执行指令。按需调用、限制额度。

新增 角色 / 场景参考管理

确认的形象 → 版本化角色参考、场景图与风格约束。优先复用用户资产；生成参考图本身也要纳入费用。

扩展 模型能力与秒级报价

约束 → 可用模型、时长范围、输入要求与计费规则。默认模型冻结到计划；显式系列约束贯穿所有镜头和重跑，不静默跨系列。

扩展 图像 / 视频制作

类型化指令 → 任务 ID、状态与产物。支持 t2i、i2i、i2v 等适配；首尾帧生视频作为候选能力单独验证。

扩展 抽帧、裁剪与依赖

片段与时间范围 → 首尾帧、保留片段和依赖引用。原片时间范围、生成时长与成片采用时长分别存储。

新增 质量检查与修复建议

产物 + 需求 / 参考 → 可解释检查结果、问题镜头和修复范围。技术检测结合多模态评估；不承诺自动审美判断绝对正确。

扩展 剪辑、声音与交付

时间线 + 产物 → 拼接成片、原片包、清单。音源、字幕与配音按计划启用；默认不额外压缩，必要转码可追溯。

扩展 人工交互与版本审批

不确定项 / 变更 → 选项、影响和费用差额 → 用户选择。断点恢复、批准失效和冲突检测在统一边界实现。

复用 工作流 / MQ 执行

制作指令 → 共用队列、任务状态、执行记录。数据库事实源 + 幂等派发；Agent 规划状态与供应商排队状态分别展示。

08

四个阶段，每阶段都有可见的验收结果

先确定职责与协议，再扩大能力。先用离线回放、Mock 与故障注入验证；付费评测单独批准。

01

统一入口与最短创作链

需求理解 Agent、共享创作数据、Skill 契约与单图路由。建立成本和版本边界。

验收标准

无文本不启动；照片 + 西装照需求自动 i2i；附件类型校验；模型显式约束贯穿执行；旧工作流回归通过。

02

研究、参考资料与二次交互

研究 Agent、可替换检索适配器、多模态图片理解、角色资料与持久化问答。

验收标准

未知概念能检索有来源的候选图；多版本触发图片选项；回答后重启可续跑、不重复问；无检索结果明确报告。

03

长片导演计划与用户审核

重写 Creative / Director，分层生成故事、镜头与执行图。增加秒级报价和可编辑时间线。

验收标准

120 秒目标可核对；模型时长与引用可校验；串并行依赖无环；改镜头实时更新成本；修改使旧批准失效。

04

可靠制作、局部修复与成片

重写 Production、新增质检 Agent、依赖失效、成片交付；任务中心随状态协议同步建设。

验收标准

单段故障不重跑独立分支；未知提交不重复付费；进程重启可恢复；费用不越授权范围；原片保留、成片可播放且时长正确。

灰度与回滚：新旧计划版本隔离，新任务逐步放量；关闭新入口不破坏在途任务。追踪约束命中率、计划有效率、成片时长偏差、局部重做比例与每成片秒实际成本。
09

把取舍写进设计，而不是藏在演示里

连续性 ↔ 并发速度

尾帧继承带来串行依赖，也会传播错误。只对必要动作接续使用；硬切镜头共用参考图，可并行。

候选能力 ↔ 质量证据

首尾帧生成可接入，但画质尚无对比结论。先做受控评测再决定默认策略；t2v / r2v 也不做永久排除。

角色一致性 ↔ 生成随机性

参考图、约束和质检只能降低漂移，不能保证零漂移。重大形象选择由用户确认；修复有次数与预算上限。

费用估算 ↔ 真实结算

按秒估算必须关联模型、规格和计费规则。预留修复额度与结算对账；研究、图像和音频等费用单列。

自主创作 ↔ 审批负担

普通决策交给 Agent；仅高影响不确定性、预算变化与重要设定变化打断。六个角色按需调用，避免固定调用链。

不压缩 ↔ 必要转码

默认不以节省体积为目的压缩，保留模型原片；不同编码、转场和字幕可能需要转码，不能承诺全程无损。
