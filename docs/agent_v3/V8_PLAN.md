## 触发规则（生产意图）

触发：“反推这个视频的提示词”“测试这几条提示词的效果”“用于生产/做成模板，保留 i2i 和 i2v 提示词”“放到某系列某模板下”。
不触发：只想要一个视频或图片（“做一段……视频”）。拿不准时 Producer 用一道选择题确认，绝不默认走经典路径。

## 三种典型任务与经典分支映射

| 任务 | 用户输入 | 经典分支 | 交付 |
|---|---|---|---|
| 反推提示词 | 上传一段参考视频 | 视频理解反推 t2v →（可选）拆分为首帧 + i2v / R2V 提示词 | 提示词新版本写入模板；可选生成示例 |
| 测试提示词 | 给出 t2v / 首帧 / i2v / i2i 提示词 | t2v、首帧 + i2v、r2v、i2i 批量测试（N 张）中所选分支 | 视频/图片 + 本次提示词版本 |
| 生产任务 | 参考视频或需求 + “保留提示词” | 完整链路：反推 → 改写 → 首帧 → i2v（或 i2i 批量）→ 打包 | 成片/图片、提示词版本、经典 ZIP 包 |

## 设计要点

1. **计划节点 `run_workflow_template`**：输入为模板目标、启用分支白名单、源视频/图片引用、初始提示词、i2i 测试张数；参数为各分支模型；输出为作业 ID、视频/图片、各类型提示词版本引用、可选打包。编译时按启用分支报价（复用经典节点估价），运行时创建作业并跟踪到终态。
2. **系列与模板**：新增只读工具 `list_templates`（系列、模板、各类型提示词摘要）。计划根写 `template_target`：选已有模板，或在已有系列下新建模板。默认不修改模板配置，只经经典 PromptSync 追加提示词版本（append-only，可回滚）。
3. **写入授权**：计划审核卡明确显示“将在 系列 X / 模板 Y 下创建作业，并把提示词新版本写回模板”，需要用户勾选确认后才能批准；与普通私有计划区分。
4. **Skill 与路由**：新增 `production-workflow` Skill；Producer 增加触发规则与三种任务的可编译示例（沿用速通模式）。
5. **前端**：计划卡展示模板目标、启用分支、写回提示；结果卡给出“打开经典作业详情”链接，提示词可在经典“提示词管理”中查看。
